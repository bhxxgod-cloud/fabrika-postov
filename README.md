# ФАБРИКА ПОСТОВ — полная передача

Конвейер делает вертикальные ролики 9:16 (~12 сек) для тиктока: бьюти-разборы по фото
с рекламой сайта neironka.pro. Всё, что в этой папке, — рабочая копия на 31.08.2026.

## Что в папке
- `код/` — весь репозиторий как есть. Ничего выборочно не выдёргивалось — работает целиком.
- `ассеты/скрины-переписки/` — 75 готовых скринов «бывший написал» (12 утверждённых реплик
  × разное оформление). Кладутся в `~/Desktop/НЕЙРОНКА/ТГ-ПУЛ-БЫВШИЙ`.
- `ассеты/тг-фоны/` — обои телеграма для генерации новых скринов.
- `ассеты/комнаты/` — РЕАЛЬНЫЕ фото интерьеров: москва (18), дубай (30), неон (38).
  Кладутся в `~/Desktop/НЕЙРОНКА/КВАРТИРЫ-НА-АПРУВ/утверждённые{,-дубай,-неон}`.
  ЭТО КЛЮЧЕВАЯ ДЕТАЛЬ: комната уходит в заказ ВТОРЫМ референсом-фотографией. Описывать
  интерьер словами нельзя — модель рисует «ИИ-квартиру», проверено и отброшено.
- `девочки/исходники/` — 12 базовых фото моделей. Кладутся в `~/Desktop/НЕЙРОНКА/МОДЕЛИ-ИСХОДНИКИ`.
- `девочки/заглавные/` — готовые обложки пяти рабочих девочек → `~/Desktop/НЕЙРОНКА/ОБЛОЖКИ-ДОГЕН/<имя>/`.
- `инструменты/` — swift-бинари macOS Vision: `textbox` (текст с картинки), `facebox` (лица),
  `лицокроп.cjs`. Кладутся в `~/.neironka/bin/`. Только macOS.

## Ключи (придут отдельно от владельца, в репозитории их нет)
Владелец пришлёт три файла в личку — разложить так:
1. `rgkey` → `~/.rgkey` — RenderGrid, генерация картинок (nano-banana-pro,
   $0.025–0.03 за кадр). Баланс пополняется на rendergrid.io/portal/billing.
2. `tgtok_контент` → `~/.neironka/tgtok_контент` и `tgchat_контент` →
   `~/.neironka/tgchat_контент` — бот и чат выдачи. ВНИМАНИЕ: этот чат — группа Traffic
   владельца; для своей выдачи создай свою группу, добавь бота и замени id в tgchat_контент.
Ключи ТОЛЬКО в `~/.neironka` или `~/.rgkey`. НЕ в /tmp — macOS чистит его, и конвейер
молча встаёт («нет ключа», «нет токена») при живых ключах. Наступали дважды.

## Установка
macOS. Node 20+, python3 c numpy+pillow (`pip3 install --break-system-packages numpy pillow`),
ffmpeg (`brew install ffmpeg`). В `код/`: `npm install`. Разложить ассеты по путям выше.
Для вёрстки карточек нужен Chrome: держится общий headless на CDP-порту 9666 (`adminbrowser.cjs`).
Если сборка падает «Chrome не поднялся на 9666» — убить процессы на порту и запустить снова.

## Как устроен пост (сборка «сб2», основная)
1. **Кадр 1** — заглавное селфи девочки + хук про бывшего (2.7с)
2. **Кадр 2** — постер-разбор; через 2с поверх выезжает строка Яндекса: печатается запрос
   «нейронка про шаблоны», курсор мыши едет, КЛИКАЕТ СО ЗВУКОМ, показывается выдача (~6с)
3. **Кадр 3** — результат тренда (2.6с)
4. **Кадр 4** — скрин переписки от бывшего (0.4с, вспышкой)
Есть «сб1» — тот же конвейер без переписки, длиннее.

## Скрипты (все пути внутри `код/`)
- `генерка/assemble_girl.cjs` — оркестратор. Вызов:
  `COVER_FILE="кукла-3.jpg" COVER_REUSE=1 TPLS="img-lip-guide" OUT_DIR=... SBORKA=сб2 node генерка/assemble_girl.cjs <девочка> <номер-прохода>`
- `генерка/girlpack.cjs` — промпты кадров 3/4 по каждому тренду. САМЫЙ ВАЖНЫЙ ФАЙЛ.
- `covergen.cjs --go <исходник> <сколько>` — генерит заглавные с проверкой лица (facesim).
- `генерка/раздача.cjs <девочка> <тренды,через,запятую>` — выдаёт каждому посту СВОЮ заглавную.
  Обязательно перед параллельной сборкой: без неё потоки разбирают одну обложку.
- `yabar.py` — строка Яндекса покадрово + синтез звуков набора и клика мыши.
- `reelbuild.cjs` — склейка mp4; `cardgen.cjs`+`plates.cjs` — вёрстка карточек через Chrome.
- `генерка/сб2приёмка.cjs <папка> <маска> [--в-тг]` — приёмка + отправка. Проверяет: длину и звук,
  кадр3≠кадр1, повторы кадров 1/4 между постами, наличие постера (OCR, порог 60 знаков — у
  арт-тем не проверяется), брак ТГ-скрина (английский интерфейс, время AM/PM и др.).
  Брак сама убирает в `_брак-приёмки/`. Журнал отправок — `_отправлено.json` рядом с постами.
- `tgsend.cjs` — отправка в ТГ. Шлём ПО ОДНОМУ с подписью (имя + текст): в альбоме подпись
  видна только у первого. Сторож режет слова «тест/проверка» в подписи — это защита.
- `tt_channel.cjs` — подписи тиктока. У ВИДЕО в тт нет заголовка: подпись слитная —
  строка-реакция с эмодзи → «повторить можно так: …» → ровно 5 хештегов.
- `траты.cjs` — расходы по дням из `~/.neironka/траты.jsonl`.

## Нейминг (строго)
`<сборка>-<модель>-<тренд>-<вид>-p<проход>` → `сб2-кукла-неон-6-new-forms-видео-p4010`
Город/неон в имени заглавной («кукла-неон-5.jpg») определяет, из какого пула комнат
берутся кадры 3-4. covergen сам пишет метку места в имя.

## Правила владельца (нарушение = брак)
1. Кадр 3 — СЕЛФИ: лицо в камеру, по центру, дистанция вытянутой руки, камера чуть выше глаз.
2. ТЕЛЕФОНА В КАДРЕ НЕТ НИГДЕ. Ни в руке, ни в зеркале. Проверено болью четыре раза.
3. Кадр 4 — второе селфи ТОЙ ЖЕ съёмки: та же комната, та же одежда.
4. Дома — домашняя одежда (не куртка с улицы). У тем со сменой образа одежда задаётся темой.
5. Нос и кожа — вплотную (лицо от края до края); нос — в три четверти, анфас запрещён.
6. Запрещённые фоны: кирпичные дворы, дворы-колодцы, крыши СПб, кафе, ночные неон-переулки.
   Всё уже выключено в `locations-extra.json` → `_выключить` (с причинами).
7. Хуки — ТОЛЬКО утверждённые владельцем: `хуки-владельца*.json`, `реакции-утверждённые.json`,
   `хуки-общие-реакция.json` (в коде). Самим не сочинять.
8. Скрины переписки: 1-2 входящих, БЕЗ ответов девочки, без галочек, русский интерфейс,
   время 24ч, ник из пула (Андрей, Клоун, Бывший, Полуфабрикат, Илья 🤡, Никита 🔫).
9. Требование к постеру «непрозрачный, на весь кадр» — ПЕРВОЙ строкой промпта: хвост
   модель не исполняет (три случая полупрозрачных постеров).
10. Постинг: 1 ролик за заход, не чаще 1 в 6-8 часов, максимум 3 в сутки на акк.

## Порядок работы (новая девочка)
1. Исходник в `МОДЕЛИ-ИСХОДНИКИ` и `ДОГЕН-РАБОТА/<имя>.jpg`
2. `node covergen.cjs --go ~/Desktop/НЕЙРОНКА/ДОГЕН-РАБОТА/<имя>.jpg 14`
3. Переименовать `обложкаNN.jpg` → `<имя>-N.jpg` (метку -неон/-дубай/-бали сохранить!)
4. `node генерка/раздача.cjs <имя> "img-lip-guide,img-brow-map,..."` → пары тренд|обложка
5. Собрать по парам (см. вызов assemble_girl выше), максимум 3 параллельно — больше провайдер рубит
6. `node генерка/сб2приёмка.cjs <папка> сб2-<имя> --в-тг`

## Экономика
Кадр $0.03. Пост ≈ 2-4 новых кадра ≈ $0.10. Кеш образов: `ОБРАЗЫ/по-девочке/<девочка>/<тренд>/<обложка>/`
— повторная сборка бесплатна. Кеш сносить ТОЛЬКО той теме, чей промпт менялся.
Скрины и комнаты — разовые, дальше бесплатны.

## Грабли (каждая стоила времени или денег)
- Кириллица в переменных zsh → молчаливый parse error. Имена переменных — только латиницей.
- /tmp чистится системой: ключи, реестры — только в `~/.neironka`.
- Промпт >1900 знаков: модель отбрасывает куски. Важное — в начало.
- Два противоречащих указания в одном промпте: модель выбирает удобное ей.
- Запрет работает только в том промпте, куда вписан. Соседний кадр его НЕ наследует.
- Правку промпта проверять НА ОДНОМ посте, потом пачка. Кеш при этом снести, иначе
  кадр придёт старый и правка «не сработает».
- ffprobe нет рядом с ffmpeg-static — использовать системный (в коде уже так).
- Если DNS системы отдаёт SERVFAIL на cdn.rendergrid.io — в rgen.cjs уже встроен обход
  через 8.8.8.8 (заказ списывается ДО скачивания, терять нельзя).
