# ПЛАН: оформление акков (авка + имя + био) с панели. Согласован владельцем 28.07.

## Этап в пайплайне (ГЛАВНОЕ)
Оформление идёт СРАЗУ ПОСЛЕ первого входа, ДО прогрева и комментинга, В ТОЙ ЖЕ локальной сессии.

1. Завод акка (creds + прокси + куки → GoLogin профиль)
2. Первый вход ЛОКАЛЬНО (chlogin, GL_LOCAL=1, 0 облачных часов: часы GoLogin кончились 279/258)
3. ОФОРМЛЕНИЕ здесь же: авка + человеческое отображаемое имя + био БЕЗ ссылок
4. Прогрев 1-3 дня (лента/лайки, без комментов)
5. Комментинг: только оформленные + прогретые

Почему тут: акк-«яйцо» ловит action_block на первом комменте; смена профиля во время активного
комментинга = флаг спам-подготовки; одна сессия с логином не тратит второй заход.

## Ник (решение владельца: спорно → по умолчанию НЕ меняем)
- Меняем ТОЛЬКО отображаемое имя (безопасно, без лимитов IG).
- @username: только для свежих мусорных ников (luis493091) и ТОЛЬКО до первой активности, галочкой.
  КРИТ: смена @username меняет логин-креденшл → обязательно обновить accounts.ig_login в той же
  транзакции, иначе акк не залогинится. Дедуп везде по slug (не по нику). Лимит IG: 2 смены/14 дней.
- Био без ссылок на свежем (ссылка = промо-флаг, ловим share-restricted).

## Панель (визуально)
1. Окно завода акков: галочка «🎨 оформить сразу (авка + имя)» + источник авок.
2. Карточка акка: бейдж «🥚 без авы» / «✅ оформлен» + кнопка «🎨 Оформить».
3. Группа: кнопка «оформить всех неоформленных» (батч).
4. Блок настроек рядом со Сторожами: источник авок (генерация generateAvatar / папка), пул имён,
   шаблон био, тумблер-гейт «неоформленных не пускать в комментинг».

## Мост панель→Orbita
Панель в облаке, Orbita на маке. Мост уже написан: localrunner.cjs (слушает таблицу local_jobs).
Добавить mode='dress': панель кладёт задачу → раннер на маке выполняет локально → отчёт в панель.
