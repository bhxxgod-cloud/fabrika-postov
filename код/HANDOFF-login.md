## Данные для вставки (формат кред-строки)
Парсер панели понимает ДВА формата:
- через `:` → `login:pass:[2fa]:[email]:[email-пароль]`
- через **таб/колонки** → `логин ⇥ пароль ⇥ 2FA(base32 с пробелами)` (без почты — так шлёт часть продавцов). 2FA — строгий base32 (A-Z,2-7; в нём буква `I`, а не цифра `1`).

## Шаги логина
### 1) Завести профили (если ещё нет) — панель
Вкладка «Комменты» → «Завести аккаунты пачкой (☁ GoLogin)» → **хард-релоад** (Cmd+Shift+R) → вставить акки+прокси → группа **РАБОЧИЕ АККИ** → «Завести профили». Креды сразу пишутся в БД (даже при лимите — осядут в «⏳ Очередь», кнопка «⚙ …для очереди из БД» добьёт позже).

### 2) Логин
- Панель: кнопка **«🔓 войти во все невошедшие»** (пароль+2FA автоматом, ~30с/акк, кулдаун-гард 1ч встроен — спамить безопасно).
- Или скриптом по ОДНОМУ (с паузой ≥25с):
  ```
  SHOT_DIR=<scratch> DB_PUBLIC_URL=<pub> node chlogin.cjs "<slug>"
  ```
  Читает `цикл` экранов: лендинг→Log in, форма→логин+пароль, 2FA→TOTP (RFC6238, ключ из БД `totp_secret`), почтовый challenge→код с IMAP (imapcode.cjs; у 2FA-акков почты нет — идёт по TOTP). Исходы: `ВОШЛИ ✓` / `⛔ СУСПЕНДНУТ` (удалять) / `incorrect` (soft-block — пауза/прокси).

### 3) Проверить РЕАЛЬНЫЙ статус (не флаг!)
```
SHOT_DIR=<scratch> DB_PUBLIC_URL=<pub> node statecheck.cjs "slug1" "slug2" ...
```
(без аргументов — все comments-акки yotbonly). Заходит в профиль, классифицирует экран: `ЗАЛОГИНЕН ✓ / LOGIN-форма / SUSPENDED-БАН / CHALLENGE`. ⚠️ Лимит тарифа — **10 одновременных cloud-сессий** (воркер их тоже ест); statecheck гони ~2-3 параллельно, не больше, чтобы не отобрать слоты у комментинга. (Раньше потолок был ~3 → «профиль занят»; апнуто 2026-07-21.)

### 4) Мёртвых — удалить
Suspended/забаненных: снести GoLogin-профиль (`DELETE /browser/{id}/web` затем `DELETE /browser/{id}`) + `UPDATE accounts SET deleted_at=now(), status='paused', ig_status='suspended'`. Освобождает слот + чистит список. Собери список забаненных для претензии продавцу.

### 5) Авы (где нет) — живым
```
SHOT_DIR=<scratch> DB_PUBLIC_URL=<pub> node vavatar.cjs "<slug>"
```
Женское ИИ-лицо → в edit-профиль. ⚠️ если акк забанен, edit редиректит на бан-экран → «НЕ нашёл инпут» = проверь statecheck'ом (возможно suspended).

## Полезный SQL
```
-- статус пачки:
SELECT ig_login, session_status, ig_status, (gologin_profile_id IS NOT NULL) prof, login_fails
FROM accounts WHERE group_id='5393d525-3bc1-4092-bbfc-28a7216f961b' AND platform='comments' AND deleted_at IS NULL
ORDER BY created_at;
-- список профилей с ИМЕНАМИ GoLogin: GET https://api.gologin.com/browser/v2 (Bearer групп-токен) → {id,name}
```

## Правила (жёсткие)
- **Логин ОДИН раз на акк.** При «incorrect» — стоп, пауза, при нужде смени прокси на residential. НЕ долбить (углубляет soft-block, жжёт акк).
- **Токен GoLogin по slug — всегда `AND platform='comments'`** (иначе схватишь дубль-строку с NULL-токеном → «НЕ ПОДКЛЮЧИЛСЯ»).
- `browser.close()` НЕ глушит облачную сессию — в finally скриптов есть `DELETE /browser/{id}/web`.
- Верь РЕАЛЬНОМУ экрану (statecheck/скрин), а не флагу `session_status`.
