# Python-воркер фермы комментов (Instagram по кукам)

Заходит на аккаунты по **кукам (sessionid) + прокси**, без браузера — поэтому масштабируется
на 50+ акков параллельно (не как GoLogin, где 1 облачный профиль).

Панель (Node) кладёт акки/куки/прокси/хэштеги в общую БД → этот воркер их выполняет,
пишет пульс в `worker_heartbeat` (видно в панели) и логи в `seed_comments`.

## Как поднять на Railway (2-й сервис, рядом с панелью)

1. Railway → твой проект → **New → GitHub Repo** → выбери этот же репозиторий.
2. У нового сервиса: **Settings → Root Directory = `worker`**.
   (Так Railway соберёт только Python-воркер, а не всю панель.)
3. **Variables** нового сервиса добавь:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (ссылка на ту же базу, что у панели)
   - (необязательно) `SEED_POLL_SEC` = `150` — пауза между действиями, сек.
4. Deploy. В логах сервиса появится `[ig_comment] воркер запущен`.
5. В панели на вкладке **⚡ Комменты** индикатор станет 🟢 «Воркер в сети».

Локально: `pip install -r requirements.txt && DATABASE_URL=... python ig_comment_worker.py`
