**ЯДОВИТЫЕ ФРАЗЫ (гарантированно ломают кадр, проверено деньгами):**
- «маленькие / небольшие / компактные сердца» → модель плетёт косички на голове

- «волосы подняты руками вверх», «сердце над головой», «девушка сидит или стоит» → шапка-сердце на башке
- «лицо занимает половину кадра» → сердцам не остаётся места
- «волосы разложены по ткани» БЕЗ «от лица» → сердца разбросаны по всей кровати
- «два кадра рядом должны читаться как два разных фото» → модель рисует КОЛЛАЖ в одной картинке
