# ПРАВИЛА РАБОТЫ С ПРОФИЛЯМИ GoLogin (обязательные)

## 1. НИКОГДА не убивать профиль через pkill/kill -9
`pkill -f gologin_profile`, `pkill Orbita`, `kill -9` — **ЗАПРЕЩЕНО.**
GoLogin при жёстком убийстве **не синхронизирует профиль** → теряются куки → **аккаунт ВЫЛОГИНИВАЕТСЯ**.
Так были потеряны сессии нескольких акков 21.07.

**Только корректное закрытие:**
```js
await gl.stopLocal();      // локальный режим — синхронизирует профиль
await browser.close();
// облако: DELETE https://api.gologin.com/browser/{profile_id}/web
```
Если сессию нужно прервать — доводим до `stopLocal()`, а не убиваем процесс.

## 2. Один профиль — одна сессия
Нельзя открывать один и тот же `gologin_profile_id` дважды одновременно (две сессии дерутся,
ломают куки — «двойной драйв»). Перед запуском убедиться, что предыдущая сессия закрыта через `stopLocal()`.

## 3. Профиль залогиненного вручную акка НЕ закрывать
Если акк подняли руками (напр. `darrell85982`) — профиль не открывать и не закрывать автоматикой,
иначе слетит сессия.

## 4. Таймаут на зависание: 60 секунд
Любая браузерная операция (goto / клик / ожидание панели) **не должна висеть дольше 60с**.
Висит → релоад страницы и повтор, а не бесконечное ожидание.
```js
const withTimeout = (p, ms = 60000) => Promise.race([p, new Promise((_, r) => setTimeout(() => r(new Error('timeout 60s')), ms))]);
// при таймауте: await page.reload(...) и повторить шаг, максимум 2 раза, затем — следующая цель
```

## 5. При «Не удалось опубликовать комментарий»
Обновить страницу → повторить (до 2 попыток на цель) → перейти к ДРУГОМУ человеку.
Цель **не** писать в глобальный скип (`post_answered`) — иначе живой спрашивающий останется без ответа.

## 6. Проверка факта публикации
Успех = **композер очистился**. «Нет баннера ошибки» — НЕ доказательство (даёт ложные успехи).
