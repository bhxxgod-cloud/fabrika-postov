# Что поднять после перезагрузки мака

## 1. Раннер постинга — БОЛЬШЕ НИЧЕГО ДЕЛАТЬ НЕ НАДО
С 25.08 раннер живёт под launchd (агент com.neironka.ytrunner):
стартует сам при входе в систему и сам поднимается, если упал.
Проверить: `launchctl list | grep ytrunner` (должен быть pid и код 0).
Руками поднимать больше не нужно. Если всё же надо перезапустить:
```
launchctl kickstart -k gui/$(id -u)/com.neironka.ytrunner
```

## 2. Разовый вход в ВК (когда будет удобно)
```
cd ~/Desktop/neironka-poster && node vktoken.cjs --login
```
Войти в ВК, нажать «Разрешить». После этого токен обновляется сам, раннер чинит его без участия.
Сейчас токен свежий (взят 24.08 ~10:30 МСК), живёт сутки.

## 3. Проверить, что всё поехало
```
tail -c 600 /tmp/ytrunner.log | tr '\r' '\n' | tail -3
```
