# neironka-poster — обзор проекта

Честное описание проекта: что это, из чего состоит, тех-стек и текущее направление. Без прикрас и без вычищения — как есть.

## Продукт
**neironka.pro** — SaaS-агрегатор нейросетей и готовых промптов/шаблонов для РФ-аудитории. Пользователь заходит, выбирает эффект/задачу (например «ИИ-фотосессия»), получает подходящую нейросеть и готовый промпт-шаблон. Витрина шаблонов: `neironka.pro/#templates`. У проекта есть YouTube-канал для продвижения.

## Система (`~/Desktop/neironka-poster`)
Node/TypeScript-сервис, задеплоен на **Railway** (веб-сервис `web` + Postgres). Панель управления — веб-дашборд (`public/index.html`), бэкенд — Express (`src/api.ts`), фон — воркер/шедулер (`src/worker.ts`, `src/scheduler.ts`).

Компоненты:

### 1. Радар трендов (`src/radar.ts`)
Читает **публичные комменты** под нишевыми роликами (по списку хэштегов: «ии фотосессия», «нейросеть фото», «промт», «chatgpt» и т.д.) и считает **спрос** — сколько людей просят промпт/шаблон под ту или иную тему. Результат — приоритезированный список трендов: что добавлять в витрину `neironka.pro`. Это маркет-ресёрч на реальном спросе.
- Конфиг: `radar_config` (теги, `enabled`, `auto_reply`, `daily_limit`). Для трекинга спроса `auto_reply=false` — радар только читает.
- Данные: таблица `radar_posts` (пост, тег, кол-во комментов, `demand_hits` = спрос, `score`).
- Пост можно закрепить (`source=creator`, высокий `score`) — не выкидывается чисткой.
- Текущий топ спроса: **«ИИ-фотосессия» (12), «ИИ-фото» (7), chatgpt (5)** — прямые кандидаты в шаблоны.

### 2. Постер / контент бренда
Инфраструктура публикации контента с брендовых каналов. Аккаунты и профили ведутся через **GoLogin** (облачный браузер) на резидентских прокси. Основной брендовый TikTok — **@neironka_pro** (US-гео, свежий, чистый старт).

### 3. Инфраструктура аккаунтов
- **GoLogin** (2 аккаунта: env-токен + группа «РАБОЧИЕ АККИ») — облачные браузер-профили.
- **Postgres** (`accounts`, `account_groups`) — акки, их профили, статусы, прокси, 2FA-секреты (плейнтекст), кросс-аккаунт-дедуп.
- Панель: массовый завод профилей, вход по кредам (пароль + 2FA/TOTP локально, RFC 6238), «⏳ Очередь» для акков без профиля, авто-логин фоном.

## Тех-детали (полезное)
- Доступ к БД: `railway variables --service Postgres -e production --kv | grep DATABASE_PUBLIC_URL`.
- Панель: `web-production-efed0.up.railway.app`, пароль `DASHBOARD_PASSWORD`.
- Деплой: `railway up --service web -e production` (Nixpacks, `tsx`, без сборки).
- GoLogin: `connectOverCDP('wss://cloudbrowser.gologin.com/connect?token=…&profile=…')`; стоп сессии — `DELETE /browser/{id}/web`. Резидент-прокси: `PATCH /browser/{id}/proxy {mode:'gologin', autoProxyRegion:'us'}`.

## Куда растём (белые каналы)
1. **Контент на @neironka_pro** — свои ролики/промпты под топ-тренды из радара (сейчас «ИИ-фотосессия»), подпись + оформление профиля.
2. **Радар** как двигатель контент-плана — что просят, то и снимаем/добавляем в шаблоны.
3. **Таргет IG/VK + Яндекс/SEO** под запросы, что люди пишут в комментах.
4. **Коллабы** с профильными блогерами (открыто).

Суть: спрос на «промпты/нейросети» огромный и реальный; продукт его закрывает; задача — притащить этот трафик на `neironka.pro` устойчивыми каналами, которые не сыпятся.
